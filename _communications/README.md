# Pack 149 Communications

Reference copies of emails and announcements sent to Pack 149 families, kept here so they can be reused each year.

This folder is not part of the website. GitHub Pages skips folders that start with an underscore, so nothing here is published to bsapack149.org or linked from the site. The repository itself can still be viewed on GitHub, so never save personal details here.

## Placeholders

Use placeholders in square brackets instead of personal or year-specific details, and fill them in before sending.

| Placeholder | Replace with |
| --- | --- |
| `[CONTACT NAME]` | Name of the leader families should contact |
| `[CONTACT EMAIL]` | That leader's email address |
| `[CONTACT PHONE]` | That leader's phone number |
| `[SENDER NAME]` | Name of the leader sending the email (signature) |
| `[SENDER PHONE]` | Sender's cell number (signature) |
| `[BOBCAT DATE]` | Short date of the Bobcat Ceremony, e.g. "October 6" |
| `[BOBCAT DAY AND DATE]` | Day and date, e.g. "Tuesday, October 6" |
| `[BOBCAT TIME]` | Start time, e.g. "6:30 PM" |

Add new placeholders to this table as new templates need them.
